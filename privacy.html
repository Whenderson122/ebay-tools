Privacy Policy

Last updated: November 2026

What this application is

This application is a personal eBay listing-management tool used solely by the account owner to manage their own eBay listings, inventory, and pricing via the eBay API. It is not a service offered to the public and has no other users.

Data we access

The application accesses data from the owner's own eBay seller account via the eBay API (listings, orders, and related seller data) for the purpose of listing management, inventory tracking, and pricing research.

Data storage

Data accessed through the eBay API is stored locally on the account owner's personal computer and is not hosted on any public server. No personal data from other eBay users is collected, stored, or shared.

Data sharing

No data is sold, shared, or transmitted to any third party. Access tokens are stored locally and used only to communicate with the eBay API.

Data deletion & account closure

If the eBay account owner closes their account or requests data deletion, locally stored data can be deleted on request by contacting the owner. Because the application serves only its owner, no other users' data exists to delete.

Contact

Questions about this policy can be directed to the account owner via the contact information provided in the eBay application registration.
